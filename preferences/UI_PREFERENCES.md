# UI Preferences

- Preferred UI: **Untitled UI React**

## Our Legacy Visual Principles

### Overall direction

- Create an editorial, understated, image-led interface.
- Build hierarchy through scale, alignment, and empty space.

### Colour and surfaces

- Use warm off-white (`#FFFFFC`) as the main background.
- Use near-black (`#121110`) for primary text and controls.
- Keep the interface palette restrained around the imagery.
- Reserve purple for small status accents.
- Keep primary controls square-cornered and surfaces flat.

### Typography

- Use Inter for interface text, with Calibri and generic sans-serif as fallbacks (`"Inter", Calibri, sans-serif`).
- Rely primarily on regular and bold weights.
- Keep utility copy compact: approximately 13-14px.
- Use approximately 16-18px for longer prose, with comfortable line-height.
- Contrast small functional text with large editorial headings.
- Use uppercase selectively for major headings and navigation labels.
- Give large headings tight line-height and slightly tight tracking.

### Layout and spacing

- Align content to consistent, viewport-relative outer gutters.
- Use asymmetric desktop columns with deliberate empty space.
- Balance concise titles or supporting text against a larger primary content area.
- Start with an 8px spacing unit and a 40px section rhythm.
- Expand major editorial breaks to approximately 120-160px.
- Scale spacing to the screen and content density; preserve clear grouping.

### Page patterns

- Info: balance an oversized title against a narrow column of prose.
- Mobile: stack desktop columns and use compact image galleries.
- Interaction: favour subtle 150-250ms fades and understated controls.
