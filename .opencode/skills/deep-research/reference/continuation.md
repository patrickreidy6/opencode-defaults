# Continuing Long Research Tasks

Use when an investigation spans context windows, sessions, or an explicitly requested handoff. Report length alone does not require another agent.

## Persist useful state

Keep a compact working note alongside the report when persistence is needed. Record:

- The original question, scope, audience, and requested deliverables.
- Artifact paths and completed versus remaining sections.
- Key findings and the evidence behind them, including source URLs and useful passages.
- Citation mappings and the next unused number, if using numbered references.
- Unresolved questions, contradictory evidence, and the next concrete action.
- Checks already performed and any outstanding defects or access limits.

Reuse existing notes rather than creating duplicate state files. Preserve evidence provenance and completion status; detailed transcripts and arbitrary style metrics are unnecessary.

## Resume

Read the state and relevant report sections, verify the citation mapping against the artifact, and continue from the first unresolved item. Revisit earlier sources only when a gap, contradiction, or changed requirement makes that useful.

Stay within the original scope and complete the requested deliverables. An outline, a partial report, or a handoff note is not the finished result unless that is what the user requested.

## Delegation

Follow the user's request and applicable project instructions for subagents. When delegation is requested, give each agent a bounded question, relevant evidence and artifact paths, and an explicit expected result. Reconcile returned evidence and citation identifiers before incorporating it into the report.

## Finish

Resolve outstanding defects, complete the bibliography, and perform the [checks](quality-gates.md) relevant to the assembled artifact. Keep useful source records with saved work and report real blockers; do not delete user files as automatic cleanup.
